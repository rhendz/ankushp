# ankushp

A personal website and blog, public at ankushp.com: Next.js 16, React 19, TypeScript, contentlayer,
Tailwind. `README.md` is how it is run; `AGENTS.md` is the issue, branch and pull request workflow;
the hard rules are in `.claude/rules/site.md`.

The site runs its jobs through dispatch: a Linear issue in the "ankushp" project (team P1H), labelled
`pipeline` and moved to Ready by the developer, is planned, reviewed, built and brought to the
developer's accept card. `machinery.toml`, `openspec/` and `dispatch/` are that registration; agents
may not edit them.
